## Appearance and public interfaces

The floor shader quantizes native `XZ` sampling to `1/24` world unit and now draws larger muted leaf clusters approximately `1/1.45` world unit apart, with quieter mud patches and fewer occupied cells. Mud RGB ranges from `(0.145,0.125,0.155)` to `(0.172,0.150,0.183)`; larger muted rose/olive leaves lift local contrast around the dark rooted bulb. It uses no `TIME`, vertex displacement, alpha, emission or warning-shaped fills. Its wet leaf impression does not change movement. Faceted flutes/buttresses use opaque unshaded vertex colour; all scenic meshes have normal depth and no cast shadow. Geometry is original code-native production. Only the near folded trunks/fused roots now multiply their unchanged colour by an original generated grayscale bark albedo; no board bitmap is copied and no raster was edited or resized.

The following trunks use a dedicated sixteen-side, five-ring folded mesh with ring widths `1.10/1/0.93/0.87/0.80` and broad light/dark fold facets. The far pair retains alternating radial factors `1/0.58`. Only the near pair uses unequal radial factors `[1,.61,.96,.55,.99,.64,.93,.57,1,.60,.97,.54,.94,.63,.98,.58]` and an outward axis shift `side × radius × .25 × level²`, reaching `.3625` world unit (`.25R`) at the top. The bent top remains inside the existing `1.10R` maximum horizontal envelope; the ground pivot does not shift. Optional mesh parameters default to zero, preserving far and physical/edge-root geometry. Near bark remains red `#984654` in white-sun state and violet-red `#774864` in blue-sun state; the farther layer remains `#613c54/#534461`. The earlier sky-plane shift along the fixed camera's away axis `18Y:13Z` remains unchanged. Normal depth and the existing palette remain authoritative; current native quantization, root occlusion and camera translation have the finite fifty-view review below.

- `build(room: bool = false) -> void`: native geometry and fixed collision only. The current separately authored Latcher room is not modified.
- `floor_body: StaticBody3D`: actual floor for public scheduler geometry bindings.
- `blockers() -> Dictionary`: stable IDs to actual fixed collision bodies.
- `show_sun(state: int, stage: String) -> void`: accepts `0/1`, changes quiet floor/bark/sun palette, and lifts the incoming sun during `preview` or `lock`. The caller supplies all state and timing; no local sun timer exists.
- `follow_landmarks(hero_position: Vector3) -> void`: finite hero translation aligns the far band and the two near bands using the explicit outward-only X rule above. It reads no attack phase, source or cue and does not move floor, boundaries, bases or edge trees.
- `runtime_error() -> String`: empty means the checked native dependencies remain intact, not gameplay or visual acceptance.

Full mode currently creates seven solid bodies and eighty-eight scenic mesh instances; room mode creates five solid bodies and forty-two scenic mesh instances. Neither mode creates enemy groups, pickups, healing, abilities, contact exits or route progression.
