# Fresh ordinary entry presentation

Shared36 adds the compatible fresh-entry interface below. The [portable evidence index](evidence/shared36-runtime-validation/index.json) preserves all original scopes, including the failed reproduction. The original native reproduction closed **9 checks / 3 failures**, exit 1, on its original 99-file source subset. The corrected 90-file scope closed **75 checks / 0 failures**, exit 0, with no script, native or parse diagnostics. The directly affected existing default-writer Shell **52 / 0** and saved-gate **35 / 0** compatibility jobs also close cleanly on their separate 87- and 86-file source subsets. This is shared native construction/optics evidence, not authored level acceptance or portrait pixel review.

Ordinary construction previously copied the installed camera transform, then asked the new level's independently guarded writer for a snapshot before deriving its fresh focus. A real scene-authored displaced spawn could therefore fail live optical capture while still hidden. The fresh helper prepares the current native view before capture.

[Level](../../scripts/campaign/level.gd) adds one opt-in virtual method:

```gdscript
func snapshot_state_for_presentation(camera: Camera3D, hud: GameHUD) -> Dictionary
```

The default delegates `snapshot_state()`. An opted owner factors its checked writer so normal capture retains the actual installed camera/HUD and explicit fresh capture uses these supplied actual native instances. Both paths retain complete mechanical and optical guards. The supplied context is a receiver, never an accepted stamp; a default writer that independently reads installed HUD must explicitly adopt the hook to use the staged candidate HUD. No busy exemption is added.

[Shell](../../scripts/campaign/shell.gd) uses `_capture_fresh_candidate` only for **Journey Begin, contact-driven next main, optional/completed-level replay entry, and replay restart**. Continue, Retry and return from a side attempt retain the original saved-unit path. The fresh helper:

1. Requires the paused, ready, hidden constructor with its own actual World3D, canonical Player/effects, retained authored level Script, original native node hierarchy and current shared fixed camera policy. It records a complete nonempty exact Player packet.
2. Creates a temporary canonical HUD in a native SubViewport at the installed outer HUD's actual integral pixel dimensions. The candidate's actual objective/resources determine wrapping and the combat-safe rectangle; installed aliases are never swapped.
3. Measures the complete level-supplied source/footprint/landing/opening bounds plus the actual Player capsule, full billboard and foot shadow. Only an accepted fixed-width/basis plan moves the hidden candidate camera.
4. Checks current containment, invokes the explicit writer, and independently invokes `level.snapshot_error` outside that writer before Attempt/disk commit. Native identities/Scripts, exact Player packet, bounded corners, objective/HUD shape and actual planned camera are reread and compared before final containment.
5. Frees the staging HUD on success or rejection. A rejected candidate is disposed, with its error retained. A successful fresh packet carries that exact camera focus into installation.

The framing helper changes candidate camera and packet only; it does not move actors, replenish resources, rewrite clocks, retime actions or alter installed focus/aim/shake/HUD. Owned hooks must not mutate, emit, yield, reenter or replace aliases. Covered before/after checks reject violations; they are not a general rollback mechanism for arbitrary hostile owner code. Source/route admission and damage authority remain separately guarded.

Rejection atomicity is scoped to the fresh helper boundary. Existing next-main and side-entry operations first perform a deliberate `_record_live(false)` write; rejection does not roll that preceding durable operation back. A rejected helper itself commits no new Attempt snapshot and replaces no donor world. The native fixture records exact nonempty donor Player/level/Attempt/disk observations and temporary HUD cleanup.

Saved restoration is unchanged: pure whole-unit validation and quiet Player-to-level commit precede the existing saved-focus optical gate. A clipped saved focus is rejected, never repaired by a fresh fit. The fixture's saved-focus negative and original valid-save controls remain distinct from ordinary fresh entry.

Its in-memory accepted scene metadata is isolated from production registry acceptance. It preserves normal native focus/pause behavior and makes no screenshot, human gesture, fairness, performance, all-level or mobile claim. The archive retains its original executed source, full native/wrapper logs and closed receipt; later metadata never enters that original scope.

Both original and corrected source subsets retain the real `Registry.DATA_PATH` input, `data/campaign/registry.json`, despite a declared nonexistent `data/campaign/levels.json` seed. The actual CLI `.cinder/local.json` is retained. These are bounded literal-reference/explicit-seed subsets, not full import graphs; no missing original or later UID is inserted. Immutable offline/unexecuted source headers stay unchanged as their original provenance.
