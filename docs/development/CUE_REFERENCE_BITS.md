## Binding and comparison

Binding validates the complete original ExactJson event first. The exact canonical Cue Script is checked before virtual preflight and again before building the private derivative. Its independent, unexposed reference tree stores each expected float as eight bytes and each homogeneous three-float Array as 24 bytes. Other accepted scalar and Array/Dictionary structure remains intact. Ordinary containers are recursively frozen using the existing helper.

Every `projection_error` call still compares the supplied expected event and the current working event independently. Candidate floats are encoded freshly; no current input, native resource or accepted authority is cached. Types, signed zero, individual float bits, String keys and container sizes retain the original comparison rules. Traversal stays bounded by the already validated finite reference. Subclasses and empty references use the unchanged original two-argument comparator, preserving virtual preflight semantics.

The derivative is not serialized, returned or exposed through public getter aliases. PackedByteArray does not claim read-only enforcement. As with the original private reference, trusted Script/private-field custody is the boundary; arbitrary private-field or Script forgery is unsupported. Exact reference equality alone never authorizes a threat, damage, visibility, route or restore. Existing native parent/world/readiness, mesh/material/property/vertex/index/LOD and callback checks remain fresh.
