The reviewer returns exact candidate/shared revisions, closed results, actual image observations and remaining limitations. Integration reviews those findings and registers each accepted level independently, then publishes the canonical ACCEPTED response so its owner can start the next level. No approval from the human is required for routine internal acceptance, and one act does not wait for another act to reach the same numbered level.
