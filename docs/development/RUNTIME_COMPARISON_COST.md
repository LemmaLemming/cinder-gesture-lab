# Runtime comparison cost

The first measured reduction replaces repeated tagged JSON equality work while retaining exact values and current native authority checks. The results below concern an instrumented, headless, one-Box authored echo fixture on Godot **4.7.2.stable.official.ed1daf0bf**. They are not campaign FPS, portrait, sustained performance or latency acceptance measurements.

## Measurements and retained originals

The [native fixture](../../tests/authored_echo_performance_smoke.gd) observes one genuine authored source, the real shared Scheduler, Player, projected Cue, Cursor and renderer guard. Each successful first-cycle profile contains **72 automatic native advances**, warning/lock/active/recovery, two routed dashes and one ordinary primary. Timers surround `advance`; appended sample bookkeeping is excluded. The wider cycle wall interval includes admission, projection, separate probes, native waits and observer work.

No current world, collision, source, renderer, mesh/material, visibility, phase or callback guard is replaced by cached authority. Cue equality walks the finite validated reference, rejects candidate type/shape/key mismatches and compares float bytes. It imposes no new AuthoredSequence 1 MiB bound on projected events. The large structural Cue control explicitly fails whole-Footprint provenance; it proves transport compatibility, not new damage authority.

The Cue reference is independently cloned, private and never returned; public `projection_state()` remains a mutable defensive copy. Nested containers are marked read-only, but those flags alone are not an immutable security boundary. Matching [Array source](https://github.com/godotengine/godot/blob/ed1daf0bf/core/variant/array.cpp#L206) and [Dictionary source](https://github.com/godotengine/godot/blob/ed1daf0bf/core/variant/dictionary.cpp#L398) inspection shows native `assign` lacks the corresponding read-only guard. Custody therefore relies on keeping the reference unexposed, as the original private wire did; arbitrary private-field reflection/forgery remains unsupported. No native `assign` safety claim follows from this source inspection.

## Shared36 guarded validation changes

Shared36 retains the guarded validation changes below and their [portable original evidence](evidence/shared36-runtime-validation/index.json). The earlier sections record Shared32's original scope and measurements. Subsequent [native lifecycle work](AUTHORED_ECHO_LIFECYCLE.md) has its own evidence; it does not receive execution credit from these older profiles.

[AuthoredSequence](../../scripts/combat/authored_enemy_sequence.gd) retains the full initial snapshot safety walk and the original virtual `_input_error` / `_resolve` signatures, fresh difficulty reads, derivations, error strings and short-circuit order. Only an instance with the exact shared native Script skips three redundant LEFT subtree safety walks: `resolved_role`, `authored` and `timeline` already passed the enclosing root walk. Each newly derived RIGHT subtree still receives its full safety walk before exact typed equality. Legitimate subclasses keep all three original public comparers, because their virtual helpers can mutate LEFT aliases after root validation. The native Script choice is local and precedes those calls; no caller flag, stored token or public comparator acceptance change is introduced. Original bounds remain depth 32, 65,536 nodes, 16,384 entries per container and 1 MiB, with exact float64 bits/types and String keys.

The [Scheduler source guard](../../scripts/combat/threat_scheduler.gd), [fresh Program reader](../../scripts/combat/replay_program.gd) and [Difficulty reader](../../scripts/combat/difficulty.gd) remove repeated pure binding validation only inside one fresh source-error call. The exact native reader invokes the original public restore, collects both actual independent Difficulty parser inputs, then detaches its private sink before the actual source getter. The final binding boundary consumes that optional dependency once, compares the current exact program/epoch/generation, and freshly reads the catalogue file. Reuse requires two equal nonempty UTF8 inputs of at most 65,536 bytes and exact equality with that fresh raw read. A mismatch, absent input or larger accepted catalogue uses the original full binding validator, including staged-definition checks at their original boundary. Public restores collect no dependency; subclass dispatch and captured behavior remain unchanged.

These bytes describe the native `get_as_text()` String passed to JSON, not authenticated original file encoding. BOM or malformed encoding can normalize differently and safely take the full-validator fallback. No retained Difficulty profile, source/native getter, Script, HP, knot/stationarity, world/floor, renderer, resource or callback proof becomes cached authority. Private fields follow the existing trusted-code convention; arbitrary private reflection and concurrent external file replacement are outside this narrow same-call guarantee.

Closed focused scopes are **165 / 0** for post-root LEFT mutation / native Script controls, **116 / 0** for safety bounds and exact scalar controls, and two separate constructor runs of **76 / 0** on their respective original source sets. The source-reuse control closed **276 / 0**: 32 genuine paused controls, 16 optimized/original pairs, nonempty exact Player/Scheduler/Playback packets and native diagnostic trees, identical decisions, unchanged HP/clocks/resources and zero observed callbacks after deliberate catalogue/floor/forged-input cleanup. Its runner restores original catalogue bytes and mode under the canonical engine lock. These diagnostic native ID tags are not production snapshot transport or historical-save authority.

The guarded-subtree one-Box profile closed **113 / 0**: 72 automatic advances had p50 **60.866 ms**, p95 **63.538 ms** and maximum **119.276 ms**; 4.453473 seconds inside advances and 5.096364 seconds wall time for 1.2 simulated seconds. This is another separate instrumented headless run with variable CPU conditions, not a causal percentage or FPS result. The same-call reuse profile closed **113 / 0**: 72 automatic advances (plus a separate retained manual admission sample) had p50 **62.978 ms**, p95 **122.141 ms**, maximum **344.040 ms**, 5.313843 seconds inside advances and 5.983149 seconds wall time for 1.2 simulated seconds. The fixed-clock probe medians were source 3.914 ms, Cue 4.418 ms, reservation 4.389 ms, Cursor 2.992 ms and renderer 0.480 ms. These separate runs do **not establish a runtime gain**; Act1/Act3 cost requests remain open. The directly affected unchanged managed lifecycle scope closed **557 / 0** cleanly on its 107-file original source subset.

Original source subsets remain bounded, not complete importer/resource graphs.
