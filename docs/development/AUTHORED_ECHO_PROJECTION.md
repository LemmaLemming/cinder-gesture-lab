# Authored enemy echo projection

Shared28 projection leaf; the targeted native fixture passed179/0 on its original archived bytes. This is a presentation extension for one typed authored enemy slash. It does not authenticate an actual C52 owner, reserve an exchange, retire a cycle, move an actor or apply damage. The parent still validates the actual source, immutable definition, selected profile, cycle and admitted program before trusting a plan or binding a cue.

[ReplayFootprint](../../scripts/combat/replay_footprint.gd) adds `plan_authored(scheduler, program_snapshot, world_root, floor_regions, context)` and `projection_error_authored(projection, scheduler, program_snapshot, world_root, floor_regions, context)`. The context has exactly `world_root`, `source_id`, `source_epoch`, `generation`, `world_collision_fingerprint` and `world_floor_signature`. `world_root` is an actual live Node3D argument; it is absent from persisted output. The helper validates the [AuthoredEnemySequence](../../scripts/combat/authored_enemy_sequence.gd), then compares both its saved world and the supplied context with freshly measured native static collision and floor bindings.

The output API is `authored-echo-footprint-1`, schema 1. Its exact closed keys are `accepted`, `api_revision`, `schema_version`, `sequence_id`, `source_id`, `source_epoch`, `generation`, `profile_id`, `program_digest`, `collision_fingerprint`, `floor_signature`, `curve_segments`, `boundary_grid_m`, `fill_inset_m` and `events`. `program_digest` hashes the complete exact tagged program snapshot, including its immutable definition and world revision. It identifies the supplied program bytes; it is not a signature authenticating an arbitrary historical save. `current_world_error` and `floor_contains` support this API as a separate discriminator. A world-only check never authenticates caller mesh data.

One output event has the exact keys `event_id`, `kind`, `slot_id`, `event_ordinal`, `at_s`, `record`, `floor_y`, `triangle_vertices`, `boundary_contours` and `bounds`. Its kind is `enemy_slash`, slot is 1 and ordinal is 1. The original closed authored action record is retained exactly. It has source/role/profile identity and resolved enemy damage, with no Player equipment, capture sequence, completed-at clock or Player action provenance. The existing `replay-footprint-1` captured header and its `record_sequence` event shape remain separate.

[ThreatCue](../../scripts/cues/threat_cue.gd) accepts the authored event through its existing `projection_binding_error` / `bind_projection` / `projection_error` surface. The `enemy_slash` branch uses the authored action decoder and exact event/cycle ID, while captured primary/blast events keep their Player record decoder. Both branches use the same bounded native prevalidation, immutable mesh/material/resource and node receipts, floor offsets, phase visibility, synchronous callback order, quiet signal blocking and latched failure after lost required custody. All cue bindings must pass pure prevalidation before a parent begins a batch of silent bindings.

Clipping remains the existing finite projection model: coplanar authored domains on unscaled axis-aligned static Box floors, the original 64-segment cone boundary, complete native scenery-ray shadows from full-height Box blockers, closed outer and hole contours, and inward conservative filled cells. Low scenery wholly below the original LOS band is ignored; partial-height ambiguous blockers, unsupported topology and bounded-work/output overflow fail closed. Outline ribbons are clipped to those inward cells, so holes and shadows are not covered by native strip vertices. Presentation meshes do not participate in hit math, and no geometry, aiming, clocks, damage timing or controller collision is changed.

The new [native leaf](../../tests/authored_echo_projection_smoke.gd) is designed to inspect actual ArrayMesh fill/outline/source receipts in real Box floor worlds, a floor hole, a full-height LOS blocker and a low stone. It checks transformed-parent floor placement, phase grammar, quiet reconstruction, exact tagged JSON, source/cycle/world mutation, malformed or Player-shaped enemy records, and hidden/freed/mutated required children. Its definition and stationary source are explicitly TEST ONLY; it is not an authored C52 actor, physical replay consumer, portrait, boss fairness or campaign acceptance test. Root queues this one target after all participating source files are frozen; evidence will be updated from the closed native run.
