# Historical desktop shared smoke logs

This compact archive preserves five original local log streams byte for byte. Their printed footers report Settings 182/0, Effects settings 60/0, World actions 119/0, Threat scheduler 65/0 and Player presentation 73/0. The presentation stream also reports 5,544 poses across 11 legal kits.

These are historical logs, not new test executions. In this selection, independently retained historical source snapshots and complete invocation/queue/closed-job receipts are unavailable. A printed zero-failure footer alone does not establish an exact exit code, a clean full process lifecycle, or applicability to every later source revision. No current source files have been copied into or substituted for old inputs.

Every existing diagnostic remains intact. The presentation stream includes a resource-as-image export warning and its original stack trace; it must not be relabeled as a clean export validation. The other selected streams contain no WARNING/ERROR/Script/Parse diagnostic lines in this bounded text check. The index records hashes, original paths, footers and observed diagnostic lines; it does not reconstruct missing original custody.

This archive supplies portable provenance for existing evidence only. It adds no level acceptance, current-runtime-wide verification, authored route, visual review, human balance, sustained 30/60 FPS, mobile/export or release result. Newer exact shared and level-specific archives retain their separate stronger source/closure scopes.
