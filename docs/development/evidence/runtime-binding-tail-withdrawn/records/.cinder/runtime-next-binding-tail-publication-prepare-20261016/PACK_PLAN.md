# Binding-tail portable preservation plan

This prepares a private portable evidence pack. It makes no gain, promotion, campaign acceptance or publication decision and edits no live/docs/Git records. Root has supplied the actual113 closed cost-pair path, its final review and withdrawal decision; the final spec now pins them alongside actual81 evidence. Both engineering requests remain open.

The whitelist contains the actual81 original/candidate correctness pair, its exact selected closed seal, complete original phase indexes, raw/engine logs, native reports, source maps/retention/modes, restoration/queue receipts and source CAS. It also contains the frozen correctness host/producer controls, original unexecuted renderer-v1 leaf/readiness and v2 renderer fix, actual/source reviews, blocked unexecuted performance-host v1 and its additive custody-v2 successor. Root will add the actual113 cost pair, selected seal and exact reviews without rewriting any previous file.

`prepare_pack.py inventory` verifies only these bounded indexed phases, pinned frozen controls and explicit review files, then writes a clearly pending inventory in this private directory. It does not run/import engine/dev code, traverse worker checkouts or scan unrelated source banks. `prepare_pack.py build` refuses until the spec names a closed actual cost pair and a final Root-reviewed archive README.

The future pack lives only below this private directory. Root selected the repository-relative destination `docs/development/evidence/runtime-binding-tail-withdrawn/`, alongside its separately owned `docs/development/RUNTIME_BINDING_TAIL_WITHDRAWN.md`. The portable entry points will be `index.json` and `README.md`; `PACK_MANIFEST.json` and `RELOCATION.json` retain custody details. Every non-CAS original file is copied byte-for-byte with its observed mode. `.gd` source names are stored with an inert `.txt` suffix when needed, with explicit relocation, to avoid adding duplicate executable Godot scripts to evidence directories.

Source CAS is pooled by exact SHA256 into `objects/<sha256>.bin`. Each original CAS alias remains in `RELOCATION.json` with its original complete path, full-file hash, byte length and original physical mode, plus the storage path/mode. This is byte deduplication, not an edit to any original source map or index. Original JSON containing local/absolute paths is preserved verbatim. The separate relocation map resolves packaged paths; historical external context references remain qualified rather than triggering an archive-bank crawl. Logical original-source modes remain in the verbatim native source metadata as well as per-origin relocation metadata. Engine binary metadata is retained; the351MB executable is not invented as a retained source blob.

The builder verifies every original index row and nested index, preserves failed/nonclean/partial states, copies index files themselves unchanged, checks all source inputs again after copying, and verifies every portable artifact. Its generated manifest records exact bytes/modes and storage aliases. Original logs, profile payloads, assertions and failure results are never normalized, reserialized, replaced or relabeled as clean. Actual81 Host2 CA/API0 and its original restoration record remain as recorded. Source-only blockers/fixes receive no fabricated engine execution. Original absent UID/type observations remain in their immutable metadata.

The final archive README must distinguish actual81 correctness, actual113 inclusive timing scope, Host diagnostics, source-only v1 blocker, v2 guarded custody, original/future limitations and Root's separate decision. It must not infer CPU/FPS, causal gain, a clean run, dynamic global closure, new visual inspection or campaign acceptance. Both engineering requests remain open until Root decides otherwise.
