The first baseline rejected a test-only instrumented Scheduler Script and never admitted its workload (7/3, exit 1). Corrected original and optimized profiles use the actual Scheduler and one native Box source, headless first-cycle automatic advances. Separate fixed-clock probes are inclusive API costs with overlapping call chains and variable CPU conditions; they are not nested percentages, FPS, sustained performance or a latency threshold.

Cue controls include genuinely recorded native hole/LOS and resource/callback checks, plus labelled structural transport above 1 MiB within the existing 8 MiB bound. The large structural event is not whole-Footprint or damage provenance. Actual input/getter aliases remain defensive; all current native world, resource, visibility, material and callback guards remain required. The separate private comparison reference is unexposed. Recursive read-only flags alone are not a security boundary: matching ed1daf0bf Array/Dictionary source inspection found native assign lacks a read-only guard. Private-field reflection/forgery remains unsupported, as with the original private wire.

Spore scope is the recorded native protocol/source and direct affected fixtures, not authored A1-L3 acceptance or artwork. No complete native resource/import graph, production 16-visual enemy, campaign route, portrait capture, human input, mobile or boss-clear evidence is inferred from these jobs. Existing captured and authored first-cycle scopes retain their original attribution; offline lifecycle drafts are separate.

Each manifest is an original bounded literal res:// subset, including its originally supplied seeds and UIDs. Archived absence is disclosed, never filled from later live bytes. Index membership and every SHA256/byte count are verified. Old docs/config/tool copies retain their original bytes; later named-target or publication changes receive no retroactive execution credit.

Exact argv and permission flags absent from original closures are explicitly unknown; index invocation metadata separates integration-supplied semantic arguments from original retained command evidence. All jobs used the canonical dev engine queue. index.json excludes its own hash, which the integration owner records externally. .gdignore excludes historical sources from engine import.
