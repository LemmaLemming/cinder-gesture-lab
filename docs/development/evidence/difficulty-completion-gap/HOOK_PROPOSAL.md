# Smallest shared implementation hook

This is an inert proposal, not implemented runtime or a completion claim. It concerns the20 accepted production levels only. The four still-unimplemented optional rows and private owner worktrees were not audited; do not call the result “all other23 missing.”

Root can implement a pure helper such as `scripts/combat/difficulty_order.gd`, with a single selection entrypoint:

```gdscript
static func select(plan: Dictionary, profile_id: String) -> Dictionary
```

The explicit owner plan identifies the level/room, its baseline existing source IDs, and each Assisted/Standard/Challenge arrangement ID/order. Return a closed defensive recipe containing its version, selected arrangement ID, fixed profile ID and source order, or an explicit refusal. Validate stable String IDs, uniqueness, known profiles and an exact permutation of the existing baseline set. Reject unknown or missing plans; never invent an order from the descriptive profile label. The minimal helper changes only ordering, so new actors, omitted required targets, participation modes and geometry are outside this first API. Identical orders are permitted only with an explicit authored rationale; they do not prove more demanding Challenge behavior.

There is no clock, random draw, actor write, lease, HP/timing/geometry mutation or safe-path permission in this helper. Selection does not consume an equipment/ability allocation. It uses an existing fixed encounter profile, never a mutable menu preference during active play. It returns copies and performs no callback or engine-world traversal.
