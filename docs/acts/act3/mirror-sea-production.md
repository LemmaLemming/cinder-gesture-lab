The shore-builder change contains no raster imports. A separate original witness cutout is recorded below and remains unconsumed by this first preview. All native meshes use world units and fixed local bases; apparent pixel size comes from the shared nearest-filtered portrait renderer. Material depth remains normal and every created scenic mesh disables shadow casting. The builder creates exactly five solid bodies and no enemy, practice-target, pickup, contact or interaction groups.

`build(room: bool = true)` is idempotent for one layout; changing a built room/full selection reports an error instead of rebuilding live collision. It retains the inherited optional second argument for the parent method signature. `floor_body` exposes the actual floor; `blockers()` returns a defensive stable-ID map of the four boundaries. `follow_landmarks(hero_position)` translates only the distant band, accepts finite positions, and never moves floor/coast/solids. `runtime_error()` is a pure live-dependency check: exact untransformed world root, actual direct-parent stationary box local/global transforms, exact sizes/margins/layers, zero native velocities and first named active Solid collider, and live scenery mesh/material ancestry. An empty error means those checks hold; it is not an engine, visual or encounter acceptance result.
