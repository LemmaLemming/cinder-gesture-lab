Other negatives, NaN, either infinity and values above that bound are rejected. This prevents NaN/Infinity from bypassing the historical sample/current-clock comparison. A valid staged clock must still pass the original sample-clock join; it is not history or lease authority.

The prior `d484b92d` source and manifest are retained as `scheduler-completed-d484b92d-before-staged-fix.gd.txt` and `scheduler-manifest-d484b92d-before-staged-fix.json`, alongside the original `2197267e` evidence.
